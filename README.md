\# Beecrowd 1046 - Tempo de Jogo



\## Descrição



Este programa resolve o problema 1046 do Beecrowd.



\## Tecnologias utilizadas



\- Java

\- NetBeans

\- Maven



\## Entrada



A entrada contém dois valores inteiros que representam a hora de início e a hora de fim do jogo.



\## Saída



O programa apresenta a duração do jogo no formato:



\*\*O JOGO DUROU X HORA(S)\*\*
